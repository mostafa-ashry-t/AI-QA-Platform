# OrangeHRM Directory — TC-054 (Framework A: Playwright + TypeScript)

Generated by the `automation-generation` skill (binding `playwright-ts`) from the
approved TestCases v1.4.0. Only TC-054 (`Needs Automation = TRUE`) is automated.
See `../AutomationGeneration.md` for the case mapping, locators and validation.

## Prerequisites

- Node.js 18+ (verified with 24.19.0), npm
- Network access to https://opensource-demo.orangehrmlive.com

## First-run setup

```
npm ci            # or: npm install
npx playwright install chromium   # browser build for the pinned Playwright 1.64.1
```

## Environment variables

| Name | Required | Purpose |
|---|---|---|
| `QA_USERNAME` | yes | Demo account user name (DATA-001) — never stored in the project |
| `QA_PASSWORD` | yes | Demo account password — never stored in the project |
| `QA_BASE_URL` | no | Default `https://opensource-demo.orangehrmlive.com` |
| `QA_BROWSER` | no | `chromium` (default), `firefox`, `webkit` |
| `QA_HEADLESS` | no | `true` (default) / `false` |
| `QA_TIMEOUT_MS` | no | Action / assertion / wait timeout (default 30000) |
| `QA_ARTIFACTS_DIR` | no | Evidence root (default `../../automation-execution/results`) |
| `QA_RUN_ID` | no | Run identifier used in evidence paths (default `local-<UTC timestamp>`) |

## Run from the command line (Claude Code)

PowerShell:

```
$env:QA_USERNAME = "<value>"; $env:QA_PASSWORD = "<value>"
npx playwright test
```

bash:

```
QA_USERNAME=<value> QA_PASSWORD=<value> npx playwright test
```

Other scripts: `npm run typecheck`, `npm run list` (discovery only, writes no reports).

## Run from IntelliJ IDEA

1. File > Open > select this folder.
2. Run > Edit Configurations > **TC-054 Playwright TS** (shared in `.run/`, Shell Script type,
   available in the Community edition): fill `QA_USERNAME` / `QA_PASSWORD` locally.
3. Run it. Results are written as described below.

## Results and evidence

`<QA_ARTIFACTS_DIR>/<run-id>/playwright-ts/`:
`html-report/` (open `index.html`, or `npx playwright show-report <dir>`), `results.json`,
`junit.xml`, and `TC-054/` with `steps.log`, `final.png` (pass) or `failure.png` + `trace.zip`
(fail; open with `npx playwright show-trace <trace.zip>`).

The login step is deliberately not traced (it types secrets on a page that shows the demo
credentials). Retries are 0.
