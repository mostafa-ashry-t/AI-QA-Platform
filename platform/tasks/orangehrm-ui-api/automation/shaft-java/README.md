- JDK 21 (`java -version`; a JRE is not enough). Verified with JetBrains Runtime 21.0.5
  bundled with IntelliJ IDEA 2024.3 (`<IDEA>/jbr`).
- Maven 3.6+ (verified with 3.9.11)
- Google Chrome; Selenium Manager resolves the driver
- Network access to https://opensource-demo.orangehrmlive.com and Maven Central

Version note: SHAFT_ENGINE 10.1.20260123 is the newest release compiled for Java 21.
Releases from 10.1.20260310 on require JDK 25.

## Run from the command line (Claude Code)

PowerShell:

```
$env:JAVA_HOME = "<JDK 21>"; $env:QA_USERNAME = "<value>"; $env:QA_PASSWORD = "<value>"
mvn test
```

bash:

```
JAVA_HOME=<JDK 21> QA_USERNAME=<value> QA_PASSWORD=<value> mvn test
```

**Windows profile path with a space** (e.g. `C:\Users\First Last`): SHAFT 10.1 runs its
Allure CLI from `user.home` without quoting, which fails the build after the test
(healing H-003). Pass the 8.3 short form of the same folder:

```
mvn test "-Dshaft.extraArgLine=-Duser.home=C:\Users\FIRSTL~1"
```

(`cmd /c for %I in ("%USERPROFILE%") do @echo %~sI` prints the short form.)

## Run from IntelliJ IDEA (Community)

1. File > Open > `pom.xml` > Open as Project. Project SDK: a JDK 21.
2. Run > Edit Configurations > **TC-054 SHAFT** (shared in `.run/`, TestNG suite `testng.xml`):
   fill `QA_USERNAME` / `QA_PASSWORD` locally. Add `-Duser.home=<short path>` to VM options
   if your profile path contains a space.
3. Run it.
